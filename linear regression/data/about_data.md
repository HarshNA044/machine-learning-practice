# About the Dataset

This dataset contains sales details spanning 36 months from the year **2011 to 2013**. It consists of **32,041 rows and 17 columns**.

## Attribute Information

| Column Name | Description |
| :--- | :--- |
| **OrderNumber** | Unique identifier for each order |
| **ProductName** | Name of the product sold |
| **Color** | Color variant of the product |
| **Category** | High-level product classification |
| **SubCategory** | Specific product sub-classification |
| **ListPrice** | Original listed price of the item |
| **Orderdate** | Date when the order was placed |
| **Duedate** | Scheduled due date for the order |
| **Shipdate** | Date when the order was shipped |
| **PromotionName** | Applied promotional campaign or discount code |
| **SalesRegion** | Geographical region where the sale occurred |
| **OrderQuantity** | Number of units purchased |
| **UnitPrice** | Price per single unit |
| **SalesAmount** | Total revenue generated from the order |
| **DiscountAmount** | Discount value applied to the order |
| **TaxAmount** | Tax charged on the order |
| **Freight** | Shipping/freight cost |
